## 摘要

Erdős–Straus 猜想断言：对每个整数 n ≥ 2，方程 4/n = 1/x + 1/y + 1/z 存在正整数解。
该问题自 1948 年提出至今未闭合，计算验证已达 10^18。本文报告一次诚实的单日推进：
不闭合主命题，而是（i）在不依赖 Mathlib 的 Lean 4 core 中，以零缺口（无 `sorry`、无自定义 `axiom`）
形式化三条无穷剩余类（n 为偶数、n ≡ 3 (mod 4)、3 ∣ n）的显式单位分分解、
提升引理（n 可解 ⟹ k·n 可解）及其合成——类覆盖定理；（ii）以精确整数算术的可复现脚本
核查 2 ≤ n ≤ 10000 的全部情形（含 1666 个难类 n 的独立搜索）。
主命题在形式化中以显式 `sorry` 留缺。因沙箱缺少仓库推送凭据，CI 未能运行，
按仓库规则降级为 L1（未验证的尝试）。标题与摘要不使用「证明/解决」等词，以与证据等级一致。

**关键词**：Erdős–Straus 猜想；埃及分数；单位分数；Lean 4；形式化；模覆盖

## 1 问题陈述

对整数 n ≥ 2，是否存在正整数 x, y, z 使得

$$\frac{4}{n} = \frac{1}{x} + \frac{1}{y} + \frac{1}{z}. \tag{ES}$$

两边同乘 n·x·y·z 得整式形式 4xyz = n(xy + xz + yz)。注意整式形式在允许分母为 0 时
会出现平凡退化（如 x = y = 0），故严格陈述必须限定正整数；本文形式化中主命题
显式带 `0 < x ∧ 0 < y ∧ 0 < z` 前提。

## 2 相关工作（真实引用）

- **提出**：Erdős 与 Straus（1948）；见 Guy《Unsolved Problems in Number Theory》(3rd ed., 2004) D11。
- **计算验证**：Salez (2014) 验证至 10^17（附 C++ 代码）；Mihnea & Dumitru (2025 预印本) 至 10^18（见 erdosproblems.com #242）。
- **解析覆盖**：Mordell 型多项式恒等式覆盖 mod 840 中除六个平方剩余类 (1, 49, 121, 169, 289, 361) 外全部类；
  Terzi (1978) 推进至 mod 120120 的 198 类（转引自 erdosproblems.com）。
- **计数与筛法**：Vaughan (1970) 证明 [1, N] 内例外数 ≤ N·exp(−c(log N)^{2/3})；
  Elsholtz–Tao (2013) 给出素数上平均解数的 polylog 上界，并建立系统的模恒等式体系
  （n ≡ −c 或 −1/c (mod 4ab)，gcd(a,b)=1，c 为 a+b 的奇因子）。
- **归约**：4/n 有解 ⟹ 4/(mn) 有解（分母同乘 m），故反例最小者为素数——文献标准事实，本文将其
  主方向形式化（`es_lift`）。

## 3 方法

### 3.1 形式化（Lean 4 core，v4.35.0，无 Mathlib）

以 `def ES (n x y z : Nat) : Prop := 4 * x * y * z = n * (y * z + x * z + x * y)` 表述整式方程。
三条类的显式 witness 与其验证恒等式为：

| 类 | witness (x, y, z) | 恒等式 |
|---|---|---|
| n = 2m | (m, 2m, 2m) | 1/m + 1/(2m) + 1/(2m) = 2/m = 4/(2m) |
| n = 4m+3 | (m+1, 2(m+1)n, 2(m+1)n) | 1/(m+1) + 1/((m+1)n) = (n+1)/((m+1)n) = 4/n |
| n = 3k | (k, 6k, 6k) | 1/k + 1/(6k) + 1/(6k) = 8/(6k) = 4/(3k) |

提升引理 `es_lift`：由 h : ES n x y z 经三次分配律与交换律重排得 ES (k·n) (k·x) (k·y) (k·z)。
类覆盖定理 `es_classes`：对 n ≥ 2，若 n % 2 = 0 ∨ n % 4 = 3 ∨ n % 3 = 0 则存在解；
分情形还原为 n = 2m / 4m+3 / 3k 后调用对应类定理（`omega` 处理商余关系）。
主命题 `erdos_straus_conjecture` 带正性前提并以 `sorry` 显式留缺。

### 3.2 计算核查（`scripts/erdos_straus_search.py`）

显式类直接取 witness；难类（n ≡ 1 (mod 4) 且 3 ∤ n）做无假设精确搜索：
x ∈ (n/4, 3n/4]，1/y + 1/z = (4x−n)/(nx) 化简为 a/b 后于 y ∈ (b/a, 2b/a] 枚举，
判定条件 (a·y − b) ∣ b·y。所有解回代整式方程精确校验。
